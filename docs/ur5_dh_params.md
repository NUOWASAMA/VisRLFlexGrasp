## 四、DH 参数表

### 4.1 Modified DH (Craig) 约定

**变换矩阵：**
$$ T_{i-1}^{i} = Rot_X(\alpha_{i-1}) \cdot Trans_X(a_{i-1}) \cdot Rot_Z(\theta_i) \cdot Trans_Z(d_i) $$

**参数定义：**
- `a_{i-1}`：沿 x 轴，两相邻 z 轴之间的垂直距离（连杆长度）
- `alpha_{i-1}`：绕 x 轴，两相邻 z 轴之间的夹角（连杆扭转角）
- `d_i`：沿 z 轴，两相邻 x 轴之间的距离（连杆偏距）
- `theta_i`：绕 z 轴，两相邻 x 轴之间的夹角（关节角）

## 七、提取方法说明

### 7.1 从 URDF 文件提取的步骤

1. **解析 XML**：URDF 是 XML 格式，每个 `<joint>` 和 `<link>` 节点包含完整信息
2. **运动链遍历**：从 `robot_base` 开始，按 parent→child 关系逐级计算变换矩阵
3. **关节轴方向**：每个关节的 `<axis xyz="0 0 1"/>` 指定关节轴方向（在 child link 坐标系中）
4. **坐标变换**：累计每个 joint 的 `<origin xyz="..." rpy="..."/>` 得到世界坐标
5. **DH 参数推导**：相邻关节轴的公垂线方向和夹角对应 a、alpha 参数

### 7.2 关键提取公式

```python
# URDF rpy 旋转矩阵（固定轴 extrinsic rotation）
R = Rz(yaw) · Ry(pitch) · Rx(roll)

# 齐次变换矩阵
T = [ R   p ]
    [ 0   1 ]

# 世界坐标累计
T_world = T_parent · T_joint
```
